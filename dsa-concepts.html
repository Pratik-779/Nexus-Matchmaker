1. Hash Tables (Hash Maps)

Time: O(1) Space: O(n)

Use Case: MongoDB _id indexing, Socket.io session storage, in-memory user/job storage

Backend Implementation:
// In-memory database using JavaScript Map (Hash Table)
const db = {
  users: new Map(), // Key: userId, Value: user object
  jobs: new Map() // Key: jobId, Value: job object
};

// O(1) lookup
const user = db.users.get(userId);

2. Priority Queue (Max-Heap)

Time: O(n log n) Space: O(n)

Use Case: Ranking freelancers by match score (AI Smart Match)

Backend Implementation:
// Calculate match scores
const scoredMatches = freelancers.map(f => {
  let score = 50; // Base
  if (roleMatch) score += 30;
  if (skillMatch) score += 10;
  score += rating * 2;
  return { ...f, matchScore: score };
});

// Sort by score (Max-Heap concept)
scoredMatches.sort((a, b) => b.matchScore - a.matchScore);

Try it: Search for freelancers and see ranked results

3. Bipartite Graph

Graph Structure

Use Case: Modeling Creator ↔ Freelancer relationships

Conceptual Model:
Set A (Creators) ←→ Set B (Freelancers)
- No edges within Set A
- No edges within Set B
- Jobs represent edges between sets

Schema Implementation:
User { userType: 'creator' | 'freelancer' }
Job { creator: ObjectId, assignedFreelancer: ObjectId }

5. Sorting Algorithms (Quick Sort / Merge Sort)

Time: O(n log n) average Space: O(n)

Use Case: Job feed sorting (by budget or match percentage)

Frontend Implementation:
// JavaScript's Array.sort() uses TimSort
// (hybrid of merge sort and insertion sort)
const sortedJobs = [...jobs].sort((a, b) => {
  if (sortType === 'budget') {
    return b.budget - a.budget; // Descending
  } else {
    return b.matchScore - a.matchScore;
  }
});

6. String Matching Algorithms

Time: O(n*m) naive approach

Use Case: Skills comparison in AI matchmaking

Backend Implementation:
// Check if skill matches using substring search
skills.forEach(skill => {
  const skillMatch = freelancer.skills.some(fs =>
    fs.toLowerCase().includes(skill.toLowerCase()) ||
    skill.toLowerCase().includes(fs.toLowerCase())
  );
  if (skillMatch) score += 10;
});

7. WebSocket Communication (Socket.io)

Time: O(1) per broadcast

Use Case: Real-time Kanban board updates across multiple clients

Server Implementation:
io.on('connection', (socket) => {
  socket.on('taskMoved', (data) => {
    // O(1) broadcast to all other clients
    socket.broadcast.emit('taskUpdate', data);
  });
});

Client Implementation:
socket.on('taskUpdate', (data) => {
  // Update UI without page reload
  updateKanbanBoard(data);
});
